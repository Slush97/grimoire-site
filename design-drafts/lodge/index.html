Keeping Deadlock mods in order since 9 January 2026
Grimoire revision 1.28.0, 19 August 2026
This page last updated 26 August 2026

Grimoire is a desktop mod manager for Deadlock. It mirrors the GameBanana catalog into a local database, keeps what you have installed in an ordered list, and writes the result into the game's addons folder. Windows, Linux and macOS. MIT licensed.

One program by one maintainer, first released 9 January 2026. Four things make up most of the work:

  1. I

    The catalog

    The full Deadlock library on GameBanana, mirrored to your machine and searched locally, so filtering is instant and stays usable when the site is slow. Install straight from a mod page with the one-click handler.[1]

  2. II

    The library

    Toggle, reorder, prioritise. Two mods that write the same path inside the game's VPK tree are found and named before they take a match down with them.[2]

  3. III

    The Hero Locker

    One active skin per hero, chosen from every variant you have installed. The rest stay on disk, ready to swap. Sounds, effects and cards work the same way.

  4. IV

    Profiles

    A whole loadout saved and restored in one click. Export as a short mp1: code that fits in a chat message, or as a .modprofile.json file.[3]

Also included

  • Crosshair designer with live preview and saved presets
  • Autoexec manager for console settings, kept in one file
  • Collection import of a whole GameBanana collection by URL
  • Conflict detection across overlapping file paths
  • Player stats for MMR, match history and heroes
  • Sound previews before a sound mod goes in
  • Snapshots of a working setup, to roll back to
  • Performance presets for lower-end machines
  • Server browser fed by the Deadworks relay
  • Vanilla launch that moves your mods aside and puts them back
  • Auto-update for new releases, on by default

Guides

Twenty-seven pages ship inside the app and mirror here. The ones people open first are first run, installing mods, load order, the Hero Locker and troubleshooting. The rest cover appearance, autoexec, conflicts, crosshairs, profiles and profile sharing, servers, snapshots, stats and the experimental corners.

Notes

  1. [1] GameBanana's one-click button hands the mod to whichever manager holds the gb1click:// handler. Grimoire claims it at install time and you can hand it back. ↩
  2. [2] Two mods can each be fine and still be fatal together: same path inside the VPK tree, last one loaded wins, and the game notices at the worst moment. Load order decides it, once you can see it. ↩
  3. [3] An mp1: code is the mod list, not the mods. Anyone who opens it pulls the same mods from GameBanana themselves. ↩
  4. [4] Installers only. The raw GitHub total is roughly five times larger because every running copy polls latest.yml and pulls .blockmap files during updates, which counts existing users over and over and new ones not at all. ↩
